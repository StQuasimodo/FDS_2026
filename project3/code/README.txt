The source code is divided into 3 files, main.c, graph.c, dijkstra.c. 
main.c is the main function of the program. 
graph.c includes functions relative to building the graph. 
dijkstra.c include the function to check if the input sequence is a dijkstra order. 

For the convenience of testing, I put 8 testing samples in input.txt and 1 largest_scale tesing sample in max_input.txt. 
1. If you want to input the testing samples from the keyboard, you can comment out the "freopen" sentence . 
2. If you want to test the largest-scale testing case, please change the "input.txt" in line 13 main.c into "max_input.txt".
